# actuarial-workflow

Tools for the actuarial team's day-to-day work.

| Folder | What it is |
|---|---|
| [`email-pipeline/`](email-pipeline/README.md) | Drag an Outlook email into a folder: Claude works out which process it belongs to (e.g. a large loss advice), extracts what that process needs, ordinary code checks and computes the figures, and the result is posted to Teams. Runs locally with your own Claude subscription. |

Start with [email-pipeline/README.md](email-pipeline/README.md) for setup.
